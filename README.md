# Package Mockup Studio

ボードゲームや同人グッズの「箱・カード・駒」を、手元の画像から3Dモックアップにするブラウザアプリです。

- 化粧箱(身蓋箱・キャラメル箱・スリーブ箱)— 展開図の画像を貼って、面の配置や箱のサイズを合わせる
- カード・トークン・型抜き(透過PNGの輪郭で抜く)・厚紙チップ(フチの丸み)
- スタンド駒(差し込みの足・台座)、ダイス
- 被写界深度・ライティング・質感(マット/グロス/網目エンボス)、PNG書き出し
- プロジェクトの保存/読み込み(`.pmstudio` ファイル)、ブラウザへの自動保存

React + three.js + Vite 製で、Windows・Mac どちらでも同じように動きます(OS固有の処理はありません)。

## 必要なもの

- [Node.js](https://nodejs.org/) 18 以上(LTS 版推奨)
- ブラウザ(Chrome 推奨。理由は下の「ブラウザについて」)

## セットアップと起動

```bash
git clone <このリポジトリのURL>
cd package-mockup-studio
npm install
npm run dev
```

ブラウザが自動で開きます。開かない場合は、ターミナルに表示される `http://localhost:5173` を開いてください。終了はターミナルで `Ctrl + C`(Mac も同じ)です。

### Mac の場合

手順は上と同じです。Node.js は公式サイトのインストーラか、Homebrew(`brew install node`)で入れてください。

## サーバーなしで使う(1ファイル版)

```bash
npm run build:standalone
```

`standalone/package-mockup-studio.html` ができます。このファイルを Chrome にドラッグするか、ダブルクリックで開くだけで使えます(開発サーバー不要)。人に渡すときはこの1ファイルだけ送ればOKです。見た目のスタイル(Tailwind)とフォントはネットから読み込むので、インターネット接続は必要です。

通常の配布用ビルドは `npm run build`(`dist/` に出力)です。

## 操作

画面左上の「?」に一覧があります。主なもの:

| 操作 | Windows | Mac |
| --- | --- | --- |
| 選択 / 移動 | クリック / ドラッグ | 同じ |
| 視点を回転 | 何もない所をドラッグ | 同じ |
| 選択物を回転 | 右ドラッグ | 2本指で押したままドラッグ(副ボタンのドラッグ) |
| 視点のパン | 中ボタンドラッグ / Space+ドラッグ | Space+ドラッグ |
| 範囲選択 | Shift+ドラッグ(何もない所) | 同じ |
| 複数選択に追加 | Shift / Ctrl+クリック | Shift / ⌘+クリック |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z) | ⌘Z / ⌘⇧Z(⌘Y) |
| 保存 / 開く | Ctrl+S / Ctrl+O | ⌘S / ⌘O |
| 画像を貼り付けて配置 | Ctrl+V | ⌘V |

ショートカットは Ctrl と ⌘ のどちらでも効きます。Mac では画面上の表記も ⌘ / ⌥ になります。

## ブラウザについて

- Chrome(と Edge)では「保存」が同じファイルへの上書きになります。Safari / Firefox では毎回ダウンロードとして保存されます(中身は同じで、どちらでも開けます)。
- Illustrator からコピーした図形を貼るときは、Illustrator の環境設定「クリップボード処理」で「SVGコードを含める」をオンにしてください。実寸のまま貼り付けられます。

## ファイル構成

- `src/PackageBoxMockup.jsx` — アプリ本体(3D表示・状態・インスペクタ)
- `src/components/` — 各パネルとダイアログ(展開図の配置、トリミング、変形ボックスなど)
- `src/lib/` — 形状の生成(箱・ダイス・スタンド駒・フチの丸み)、接地計算、保存形式など
- `docs/` — 補足資料とスクリーンショット
- `vite.config.js` — 1ファイル版(`build:standalone`)の設定もここにあります
